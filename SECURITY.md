# Security policy

Layte Panel runs a root helper on servers, so we take vulnerabilities seriously.

**Please don't report security issues in public issues.** Use GitHub's private vulnerability reporting instead: open this repository's **Security** tab and choose **Report a vulnerability**. Include the version (`layte version`), the steps to reproduce, and the impact.

Security fixes are released for the latest minor version. How the panel is built to be safe is described in [docs/security.md](docs/security.md).
